# Blastlog theme for Playnite: credits

This theme is Playnite's own default desktop theme with Blastlog's colours, type and panels applied on top.

- **Base:** Playnite's "Default" desktop theme, by Josef Nemec and the Playnite contributors,
  from https://github.com/JosefNemec/Playnite (release 10.63), under the MIT License. The licence is included as
  `PLAYNITE-LICENSE.md` next to this file. The theme's XAML is theirs; Blastlog changed the colours, font sizes, corner
  radius and font in `Constants.xaml`, and added the Blastlog elements to the game details views.
- **Blastlog's elements** (`Blastlog_Status`, `Blastlog_GamePanel`) come from the Blastlog for Playnite extension;
  without it installed they show nothing.
- **Font:** Outfit (SIL Open Font License), used when installed on the PC: https://fonts.google.com/specimen/Outfit.
  Segoe UI otherwise.
